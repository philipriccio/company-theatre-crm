# ⚠️ EMAIL SEND SAFETY — READ BEFORE EVERY SEND

## TRIPLE-CHECK BEFORE SENDING ANY CAMPAIGN

1. **WHO are you sending to?**
   - Mode "All" = ~11,755 subscribers. THIS IS THE ENTIRE DATABASE.
   - Mode "Tags" = filtered subset — verify the tag count before sending
   - **NEVER hit Send on a test campaign set to "All"**

2. **Is this a TEST or a REAL SEND?**
   - Test sends go to ONE email address via the test field
   - Real sends go to the full recipient list
   - The UI has BOTH buttons — do not confuse them

3. **Confirmation text required**
   - The send dialog requires typing "SEND" to confirm
   - Still re-read the recipient count before typing it

## HISTORY OF NEAR-MISSES
- Old Mildred nearly sent test campaigns to the full 14,140 contact database multiple times
- The confirmation dialog was added as a safeguard — it is not a rubber stamp

## SAFE TEST WORKFLOW
1. Create/edit campaign in draft
2. Use "Send Test" to philip@companytheatre.ca (or janice@) first
3. Philip reviews and approves
4. THEN send to real list — always with Philip's explicit approval first
