## Issues Found

### CRITICAL (must fix before March 31)

**1. hello@companytheatre.ca was never created**
The Campaign model defaults `fromEmail` to `hello@companytheatre.ca` but this address doesn't exist in Google Workspace. Emails sent from it will fail or go to spam. Only `philip@companytheatre.ca` is verified with SendGrid. All campaigns for March 31 MUST use `philip@companytheatre.ca` until this is set up.

**2. No rate limiting on send — could hit SendGrid limits**
The send route loops through all 11,755 contacts with a 100ms pause every 10 sends. At that pace, sending to the full list takes ~20+ minutes and could hit SendGrid rate limits. For a 11k+ list, we should send in batches or use SendGrid's bulk send API. Need to test this properly before March 31.

**3. TypeScript error in contacts API**
`src/app/api/contacts/route.ts` line 40 has a type error (`source` field). Won't break production but should be cleaned before any dev work touches that file.

### UX/Design Improvements (for a stronger send experience)

**Campaigns list**
- No filter by status (Draft / Sent / Scheduled) — hard to find drafts in a growing list
- Date format inconsistent (some show year, some don't)
- 0% opens/clicks on the one sent campaign — unclear if tracking is working or just low engagement
- No search
- The orange dot on nav items has no explanation

**Contacts list**
- Sorted by email hash (cryptic), should default to alphabetical by name
- Location column is almost entirely empty — wastes space
- Column headers not sortable
- No export button (only import)
- No filter by subscription status
- No bulk actions (bulk tag, bulk export)
- No engagement data per contact (last emailed, last opened)

**Campaign send flow**
- The "Send Test" and "Send Campaign" buttons are both visible together — easy to confuse
- Recipient count shown before confirming but not prominently enough
- No preview of what the email will look like before sending to full list

**Template builder**
- Functional but basic — 8 block types
- No Company Theatre branded templates saved yet
- No way to preview as mobile vs desktop

**Dashboard**
- "Recent Campaigns" only shows sent campaigns — drafts/scheduled not visible here
- No engagement summary (total opens, total clicks across all campaigns)
